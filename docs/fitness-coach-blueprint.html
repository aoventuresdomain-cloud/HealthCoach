Phases to the goal (16–20 weeks)

Phase 1 · wk 1–6
Cut and rebuild, −3 to −4 kg. Ramp: wk 1–3 = 3 strength + 1 run + basketball
Checkpoint 1
Claude review
Phase 2 · wk 7–12
Cut, calories from the weight trend
Break · wk 13–14
Maintenance, ~2,400–2,500 kcal
Phase 3 · wk 15–20
Final cut to ~10–12% body fat
Checkpoint 3
Maintain, keep going or build

Architecture

Build and delivery

Claude build teamwrites code and content in the private GitHub repo
Xcode Cloudbuilds and runs tests on every change; monthly scheduled build
TestFlightupdates the app on your phone automatically

On the iPhone

SwiftUI appToday, workout player, meals, shopping, progress, onboarding, settings
Live Activity extensionlock-screen and Dynamic Island timer
CoachCore (Swift package)planner · rules engine · progression · stall flag · import parser. No iOS dependencies; fully tested
DataSwiftData: one versioned profile, logs, photos. Content files: programmes, exercises, recipes, lunch orders
iOS servicesAlarmKit · Health (weight, steps) · Calendar (only if IT allows) · local notifications · iCloud backup with Advanced Data Protection

Outside services (all £0)

Open-Meteohourly weather, no key
Claude appcheckpoint and stall reviews via share and import; no API
Shops and recipe boxa search link per item; no API
ExerciseDB V1GIFs bundled at build time

No server and no AWS in v1. Nothing leaves the phone except the summary you choose to share with Claude, and the iCloud backup.

Milestones and gates

  • M0 (3–4 days): pipeline to the phone; 14 alarms fire locked, on Silent and in Focus, and survive an app update (re-set on next open if not); calendar route; Live Activity timer; GIFs. Gate 0
  • M1 (weeks 1–2): onboarding, Phase 1 programme, Today screen, workout player, one-tap logging, progression
  • M2 (week 2): Sunday prompt, wake times, 14-day alarms, weather swap, notifications, Health. Gate 1: the app replaces paper
  • M3 (week 3): meals around the box, top-up list, lunch orders
  • M4 (week 4): rules engine, stall flag, Claude import, progress view. Gate 2: Checkpoint 1 at week 6
