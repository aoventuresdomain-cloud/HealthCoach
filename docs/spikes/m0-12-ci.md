# M0-12 · GitHub Actions CI

Workflow: `.github/workflows/ci.yml`, one job on a GitHub-hosted `macos-26` runner (newest Xcode 26).

1. `swift test` in `CoachCore`.
2. `xcodebuild build` of the `HealthCoach` scheme (app + embedded `LiveActivity.appex`) for an iOS 26 iPhone Pro simulator, `CODE_SIGNING_ALLOWED=NO`. The step fails unless the build succeeds and the extension is embedded.
3. Screenshots (`.github/scripts/screenshots.sh`), saved as the `simulator-screenshots` artefact for 30 days: Spike tests screen, Live Activity layouts, timer running, real Live Activity in the Dynamic Island. They run on `main`, on manual runs, and on PRs that touch `App/`, `LiveActivity/`, `Shared/` or `.github/`.

## Blocking merges
The repo is private on the GitHub Free plan, which has **no branch protection or rulesets for private repos**. GitHub can't stop a merge on a red run. The rule is enforced by process: the Head of Engineering, the only one who merges, merges only on a green **Build and test** check. Making GitHub enforce it would need GitHub Pro (paid), which is not planned.

## Minutes (free plan, spending limit £0)
- Free plan: 2,000 minutes a month for private repos. macOS runners count **10×**, so about **200 macOS minutes** a month. With a £0 limit, runs stop when the minutes run out; nothing is charged.
- Estimate per run (cold, no cache): checkout and Xcode select ~1 min, `swift test` ~2 min, app build ~4–5 min, screenshots ~2–3 min. **About 8 min without screenshots, about 10 with.**
- Saving rules already in the workflow: docs-only and Markdown-only changes skip CI, a newer push cancels an older run of the same branch, and screenshots run only when screens or CI changed.
- **Budget:** ~200 min ÷ ~9 min ≈ **20–22 runs a month**. A typical PR is one or two pushes plus the run on `main` after merge, so roughly **8–10 code PRs a month**.
- If we get close: batch small PRs, skip the run on `main` (the PR run already proved the same squash), or run Linux-only `swift test` for CoachCore-only PRs (1× minutes). Measured times go here after the first runs.
